## 1. Что означают слова из задания

| Слово | Объяснение |
|---|---|
| Репозиторий | Папка проекта вместе с историей изменений Git. |
| Git | Программа, которая ведёт эту историю. |
| GitHub | Сервис, где хранится удалённый репозиторий. |
| Clone | Получить локальную копию репозитория вместе с историей. |

Сохранить файл, сделать commit и выполнить push — три отдельных действия. После Ctrl+S изменяется файл на компьютере. После commit появляется запись в истории. После push эту запись получает GitHub.

## 2. Полный цикл командами

Инструкция ориентирована на Windows. Открой PowerShell в папке, где хочешь хранить учебные проекты. Каждую команду вводи отдельно и нажимай Enter. Если команда завершилась ошибкой, сначала разбираемся с ней.

Проверь наличие программ:

```powershell
git --version
python --version
```

Первая показывает версию Git. Вторая должна показать Python 3. Если в Windows Python запускается через `py`, используй `py main.py` вместо `python main.py` ниже.

**Сначала клонируем:**

```powershell
git clone https://github.com/MEDVEDOED/programming-techniques-practice-1.git practice-1-cli
```

`git clone` скачивает репозиторий; ссылка указывает источник; `practice-1-cli` задаёт имя новой локальной папки. Репозиторий приватный: при запросе входа авторизуйся своим аккаунтом GitHub через предусмотренное Git окно браузера. Подключение GitHub к чату само по себе не авторизует Git на компьютере.

```powershell
cd practice-1-cli
```

`cd` переводит терминал в папку проекта. Следующие команды Git относятся к этой папке.

**Создаём ветку до редактирования файлов:**

```powershell
git switch -c Suhoveev_Danila_123_321_cli origin/main
git branch --show-current
```

`switch` переключает ветку. `-c` означает «создай новую». `origin/main` задаёт исходную версию. Вторая команда должна вывести `Suhoveev_Danila_123_321_cli`. Создание ветки от `main` не изменяет `main`. Подробнее — [документация git switch](https://git-scm.com/docs/git-switch).

Почему добавлено `_cli`? Основная ветка `Suhoveev_Danila_123_321` уже содержит подготовленную работу. Для самостоятельного повторения каждого способа используем отдельную ветку с фамилией, именем, группой и суффиксом. Это позволяет начать каждый пример с исходного README и увидеть собственный новый commit.

Теперь открой папку в редакторе. Создай файл **main.py** и перенеси код из раздела 6. Имя файла должно заканчиваться на `.py`, а не `.py.txt`. Сохрани его.

```powershell
python main.py
```

Вводи по одному числу на каждый вопрос: `10`, `6`, `4`, `25.4`. Ожидаемые результаты: `32.00 см²` и `10.00` дюймов.

**Готовим изменения:**

```powershell
git status
git add main.py
git diff --cached
```

`status` показывает текущую ветку и изменённые файлы. `add main.py` выбирает именно наш файл для коммита. `diff --cached` показывает выбранные изменения: проверь, что там нужная программа. Если открылся просмотрщик, нажми `q`, чтобы выйти.

**Сохраняем изменения в историю:**

```powershell
git commit -m "Complete practice 1 via command line"
```

`commit` создаёт запись в истории. `-m` задаёт её описание. Если Git сообщает `Author identity unknown`, укажи реальные данные автора только для этого репозитория:

```powershell
git config user.name "Suhoveev Danila"
git config user.email "EMAIL_FROM_YOUR_GITHUB_SETTINGS"
```

Вместо `EMAIL_FROM_YOUR_GITHUB_SETTINGS` вставь свой подтверждённый email GitHub или свой адрес noreply из настроек GitHub. Затем повтори commit. Выдуманный email использовать не нужно.

**Отправляем свою ветку:**

```powershell
git push -u origin Suhoveev_Danila_123_321_cli
```

`push` отправляет коммиты, `origin` указывает репозиторий, следующее слово — нашу ветку. `-u` запоминает связь локальной и удалённой ветки. После успешной первой отправки в этой ветке обычно достаточно `git push`.

```powershell
git status
git log -1 --oneline
```

Проверь чистое рабочее дерево и свой последний commit. Открой GitHub, в переключателе веток выбери `Suhoveev_Danila_123_321_cli` и убедись, что виден `main.py`. Наличие файла только на компьютере ещё не подтверждает отправку.

## 6. Программа целиком

Выбраны две формулы:

- Площадь трапеции: **S = (a + b) × h / 2**, где `a` и `b` — длины параллельных оснований, `h` — перпендикулярная высота. Все вводим в сантиметрах, площадь получаем в см².
- Перевод длины: **дюймы = сантиметры / 2.54**. Один дюйм равен 2.54 см.

В задании разрешено выбрать математическую формулу; сложная собственная формула — альтернативный вариант. Поэтому площадь трапеции подходит.

```python
def calculate():
    a = float(input("Введи первое основание трапеции a, см: "))
    b = float(input("Введи второе основание трапеции b, см: "))
    h = float(input("Введи высоту трапеции h, см: "))

    area = (a + b) * h / 2
    return area


def convert():
    centimeters = float(input("Введи длину в сантиметрах: "))

    inches = centimeters / 2.54
    return inches


print("Практическая работа №1")
print("Вводи положительные размеры, дробные числа — через точку.")
print("1. Считаем площадь трапеции")

area_result = calculate()
print(f"Площадь трапеции: {area_result:.2f} см²")

print()
print("2. Переводим сантиметры в дюймы")

inches_result = convert()
print(f"Длина в дюймах: {inches_result:.2f}")
```

В `main.py` дополнительно есть комментарии с названием работы, именем и группой. Комментарии начинаются с `#` и не выполняются.

## 7. Разбираем каждое действие программы

**`def calculate():`** — объявляем функцию с именем `calculate`. Слово `def` начинает определение функции, круглые скобки здесь пустые, потому что аргументы мы не передаём. Двоеточие начинает её тело. Само определение ещё не запускает вычисления.

**Отступ в четыре пробела** показывает, какие строки относятся к функции. Когда отступ заканчивается, заканчивается и её тело. Пустые строки лишь помогают читать код.

**`a = float(input(...))`** — эту строку удобно читать изнутри. Сначала `input` выводит вопрос и ждёт ответа с клавиатуры. Введённое значение приходит как строка: например, `"10"`. Затем `float` превращает её в число `10.0`. Знак `=` сохраняет результат в переменную `a`. Здесь `=` означает присваивание.

Почему `float`, а не `int`? Размер может быть дробным: например, `7.5`. Нам нужно сохранять такие значения. `input` сам по себе числом ответ не делает: две строки `"10" + "6"` дадут `"106"`, а числа `10.0 + 6.0` дадут `16.0`.

**Строка с `b`** так же получает второе основание. **Строка с `h`** получает высоту. Это три разных переменных, чтобы одно значение не затёрло другое.

**`area = (a + b) * h / 2`** выполняет формулу. Скобки заставляют сначала сложить основания. Затем умножаем на высоту и делим на два. При `a = 10`, `b = 6`, `h = 4` получится `(10 + 6) * 4 / 2 = 32`. Без скобок порядок вычислений был бы другим.

**`return area`** завершает функцию и отдаёт вычисленное значение туда, где её вызвали. Сам по себе `return` ничего не печатает.

**`def convert():`** объявляет вторую функцию. **`centimeters = float(input(...))`** спрашивает длину, превращает ответ в число и сохраняет его. Названия переменных выбраны так, чтобы было понятно, что в них находится.

**`inches = centimeters / 2.54`** переводит сантиметры в дюймы. Делим, потому что в одном дюйме 2.54 сантиметра. Для `25.4` см получится `25.4 / 2.54 = 10` дюймов. **`return inches`** возвращает результат.

После объявления функций Python доходит до **`print("Практическая работа №1")`** и печатает заголовок. Следующий `print` объясняет формат ввода, ещё один сообщает, что сейчас считаем площадь. Кавычки обозначают текст строки и сами на экран не выводятся.

**`area_result = calculate()`** — вот здесь первая функция действительно запускается. Программа спрашивает три числа, вычисляет площадь, выполняет `return area` и сохраняет вернувшееся число в `area_result`. Локальная переменная `area` внутри функции и переменная `area_result` снаружи — разные имена.

**`print(f"Площадь трапеции: {area_result:.2f} см²")`** выводит текст вместе с результатом. Буква `f` перед кавычками включает подстановку выражений в фигурных скобках. `{area_result}` подставляет значение переменной, а `:.2f` показывает его с двумя цифрами после точки. Это форматирование вывода; само сохранённое число от него не изменяется.

**`print()`** без аргументов печатает пустую строку. Так отделяем два результата. Следующий `print` сообщает о переводе единиц.

**`inches_result = convert()`** запускает вторую функцию и сохраняет полученное число. Последний `print` показывает его с двумя знаками после точки.

В этой работе используются `str` для сообщений и ввода, `float` для измерений, а литерал `2` — целое число `int`. Специально добавлять `bool`, все арифметические операции или отдельное меню не требуется: в справке они приведены для знакомства.

## 8. Проверка результатов

Программа проверена на следующих корректных вводах:

| a, см | b, см | h, см | Длина, см | Площадь, см² | Дюймы на экране |
|---:|---:|---:|---:|---:|---:|
| 10 | 6 | 4 | 25.4 | 32.00 | 10.00 |
| 7.5 | 3.5 | 2 | 2.54 | 11.00 | 1.00 |
| 1 | 1 | 1 | 1 | 1.00 | 0.39 |

Последняя строка показывает округление при выводе. Точное математическое значение `1 / 2.54` не равно `0.39`; на экране оставлены два знака.

Это начальная учебная версия: она предполагает корректный числовой ввод и не проверяет положительность или конечность чисел. Буквы, пустой ответ или число с запятой вызовут `ValueError`; отрицательные размеры дадут бессмысленный для геометрии результат. Вводи положительные конечные числа, дробную часть отделяй точкой. Обработка ошибок может быть отдельным следующим упражнением.
